So I stopped saying "trust me bro" and started keeping receipts. Recruiters don't want vibes. They want proof.

## The one rule

Lock the call. Then let reality grade it.

- **Public data only.** SEC filings, government numbers, exchange feeds. Nothing paid, nothing borrowed.
- **Sealed first.** 21 forecasts sit on two hash-chained ledgers, fingerprinted before the outcome existed. Future-me can't quietly edit past-me.
- **Graded out loud.** Hits and misses, same page, same font size.

Great habit or mild personality disorder? Probably both.
